Code Quest: Robot Instructions

Start here: choose one quest level, test your commands with a grown-up robot, then write one win in the Coder Log.

Programming skill: give clear step-by-step instructions, test them, and improve them like a real coder.

Command Toolkit

A good command tells the robot exactly what to do. Try commands like these before writing your own:

  • move forward 3 inches
  • turn right
  • stop at the book
  • repeat 4 times

Quest Ladder

1. Sequencing

Pick a toy or pencil. Write 5 commands that move it from one side of the table to the other.

Coder XP: +25 for commands in the right order.

2. Debugging

Ask someone to follow your commands exactly. If the toy goes the wrong way, fix one command and test again.

Coder XP: +50 for finding and fixing a bug.

3. Loops

Look for a command you use again and again. Replace it with repeat, like repeat move forward 4 times.

Coder XP: +50 for making your program shorter.

4. Conditionals

Add an if-then rule: if you reach the edge, then stop or if you hit a block, then turn right.

Coder XP: +75 for helping the robot make a choice.

5. Weekly Mini-Build

Each week, build a tiny game, maze, or drawing challenge. Save your best commands and one bug you fixed.

Coder XP: +100 for finishing the weekly build.

Big Idea

A computer follows exactly what you say. Great programmers make instructions clear, test them, fix bugs, and reuse patterns.
