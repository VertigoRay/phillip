Code Quest: Robot Instructions

Programming skill: give clear step-by-step instructions like a robot can follow.

Today's Mission

  1. Pick a toy or pencil.
  2. Write 5 commands to move it across the table.
  3. Use only simple words: move, turn, stop, repeat.
  4. Test your commands. If it does the wrong thing, fix one command.

Coder XP: +50 for testing and improving your instructions.

Big Idea

A computer follows exactly what you say. Great programmers make instructions clear, test them, and improve them.
